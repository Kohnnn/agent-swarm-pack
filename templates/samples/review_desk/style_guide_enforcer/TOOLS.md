# TOOLS.md - Style Guide Enforcer Notes

Skills define _how_ tools work. This file is for _your_ specifics — the stuff that's unique to your setup.

## Issue Priority Guide

| Priority | When to Use | Example |
|----------|-------------|---------|
| HIGH | Accessibility, brand voice, legal | Missing alt text, wrong tone, defamatory statement |
| MEDIUM | Consistency, formatting | Inconsistent heading levels, wrong date format |
| LOW | Nitpicks, preferences | Oxford comma (if not required), spacing |

## Style Checklist

### Voice & Tone
- [ ] Matches brand voice guidelines
- [ ] Appropriate formality level
- [ ] Consistent tense
- [ ] Active voice preferred
- [ ] No jargon without explanation

### Formatting
- [ ] Headings follow hierarchy
- [ ] Lists properly structured
- [ ] Paragraphs aren't too long
- [ ] White space used effectively
- [ ] Page layout consistent

### Terminology
- [ ] Brand terms used correctly
- [ ] Product names capitalized properly
- [ ] Consistent word choices
- [ ] No regional variations (unless intentional)

### Accessibility
- [ ] Alt text for images
- [ ] Link text is descriptive
- [ ] Color contrast sufficient
- [ ] Screen reader friendly
- [ ] Keyboard navigable

## Common Style Issues

- Heading levels skipped
- Inconsistent date/number formats
- Oxford comma (or missing)
- "And" vs "&" inconsistency
- Single vs double quotes
- Em dash vs en dash vs hyphen
- Smart quotes vs straight quotes
- "Email" vs "email"
- "OK" vs "Ok" vs "okay"
