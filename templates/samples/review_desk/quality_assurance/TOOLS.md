# TOOLS.md - Quality Assurance Notes

Skills define _how_ tools work. This file is for _your_ specifics — the stuff that's unique to your setup.

## Test Coverage Framework

### Critical Path Testing
- [ ] Primary user workflows work end-to-end
- [ ] Core functionality is intact
- [ ] Data persists correctly
- [ ] Error handling works gracefully

### Edge Case Testing
- [ ] Empty inputs handled
- [ ] Maximum limits respected
- [ ] Concurrent access safe
- [ ] Recovery from failures clean

### Regression Testing
- [ ] Previously fixed bugs stay fixed
- [ ] Existing functionality not broken
- [ ] Performance not degraded
- [ ] Security not compromised

## Test Result Status

| Status | Meaning |
|--------|---------|
| PASS | Test executed successfully, result as expected |
| FAIL | Test executed, result not as expected |
| BLOCKED | Cannot execute due to dependency or environment |
| SKIPPED | Test not applicable for this scope |

## Risk Assessment Guide

| Risk | When |
|------|------|
| CRITICAL | Security issue, data loss, system down |
| HIGH | Major feature broken, workaround complex |
| MEDIUM | Non-critical bug, easy workaround |
| LOW | Minor issue, no workaround needed |
| NEGLIGIBLE | Cosmetic, no user impact |
