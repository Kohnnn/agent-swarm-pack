# TOOLS.md - Fact Check Lead Notes

Skills define _how_ tools work. This file is for _your_ specifics — the stuff that's unique to your setup.

## Verification Status Definitions

| Status | Definition | Action |
|--------|------------|--------|
| VERIFIED | 2+ independent sources confirm; primary source located | Safe to cite |
| UNVERIFIED | No confirmation found; no contradiction found | Flag, note source gap |
| DISPUTED | Sources conflict; cannot determine truth | Escalate to research_lead |
| FALSE | Direct evidence contradicts claim | Flag immediately; escalate if harmful |

## Source Hierarchy for Verification

1. **Primary sources** (original documents, official statements)
2. **Peer-reviewed research** (academic journals, published studies)
3. **Established institutions** (gov agencies, major NGOs)
4. **Credible news** (outlets with editorial standards)
5. **Industry experts** (named specialists with credentials)
6. **All others** (flag for additional verification)

## Verification Checklist

For each claim:
- [ ] Primary source located?
- [ ] Independent confirmation found?
- [ ] Methodology sound (if statistical/technical)?
- [ ] Recency appropriate (data not outdated)?
- [ ] Any conflicts with other verified claims?

## Cross-Reference Standards

- **Statistical claims:** Need methodology note + data source + sample size
- **Historical claims:** Need primary document or peer-reviewed history
- **Expert claims:** Need named expert + credentials + area of expertise
- **Market claims:** Need recent data (within 6 months) + source

## Dispute Resolution

1. Document both sides with evidence
2. Note which sources are more reliable
3. Flag to research_lead with summary
4. Do NOT adjudicate yourself — present evidence, let lead decide

## Escalation Triggers

Immediately escalate when:
- Claim is verified FALSE but previously published/claimed
- Falsehood could influence important decisions
- Disputed data is central to research conclusion
- Conflict of interest suspected in sources

## Routing Reminders

- Verified claims → technical_writer for drafting
- Disputed claims → research_lead for resolution
- False claims → research_lead + flag in report
- Methodology questions → research_lead

## Guardrail Reminder

Never say "this is false" without primary source evidence. Say "unverified" or "disputed" until you have proof.
