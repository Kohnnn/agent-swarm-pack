                    ↓ Yes

                    ↓ Yes

## Style Rules

### Word Choice
| Avoid | Prefer |
|-------|--------|
| Very, really, quite | (delete or use precise word) |
| In order to | To |
| Due to the fact that | Because |
| At this point in time | Now |
| Utilize | Use |
| Implement | Do |

### Sentence Limits
- Simple: 15 words
- Compound: 20 words
- Complex: 25 words
- Average paragraph: 100 words

### Passive Voice Detection
- "was" + past participle = passive
- "is being" + past participle = passive
- Rewrite unless clarity requires otherwise

## Routing Reminders

- Major structure issues → research_lead
- Verification concerns → fact_check_lead
- Writing issues → technical_writer
- Data questions → data_analyst

## Guardrail Reminder

Never approve content you haven't fully read. If in doubt, return for revision.
